你好，我是这里的主人。这里记录我生活里的片段：旅行、日常、一些想不清楚但想留下来的时刻。

我拍得不算好，也不太会剪，但我觉得记录这件事本身就值得。如果你恰好路过，欢迎随便看看。

## 关于这个网站

这个站是静态的：所有页面在发布时就已经生成好，没有数据库，没有后台，也没有服务器需要我半夜起来重启。它跑在 Cloudflare 的边缘网络上，理论上比我本人活得久。

- 内容用 Markdown 写，存在 Git 仓库里，改错了能一键回到上一版。
- 视频托管在专门的地方，网站本身只负责展示，所以便宜、快，也不怕被刷流量。
- 评论用 Giscus，数据存在 GitHub Discussions，没有第三方广告追踪。
